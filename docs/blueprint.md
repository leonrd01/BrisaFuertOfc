# **App Name**: Arcana Smokes

## Core Features:

- Product Browsing: Allow users to browse products by category (BONGS, SEDAS, etc.)
- Product Search: Enable users to search for products using a search bar.
- Promotional Carousel: Showcase products in promotion using a carousel on the home page.
- Product Detail View: Display detailed information about a selected product, including images, description, price, and related products.
- Shopping Cart: Allow users to add products to a shopping cart and proceed to checkout.

## Style Guidelines:

- Primary color: Soft gold (#D4AF37) for accents and mystical icons.
- Background color: Off-white/cream (#F8F6F3) for card backgrounds to provide a soft, vintage feel.
- Accent color: Medium gray (#3B3B3B) to complement the soft gold and cream, for secondary elements.
- Headline font: 'Playfair' (serif) for titles, providing a stylish and classic aesthetic. Note: currently only Google Fonts are supported.
- Body font: 'Inter' (sans-serif) for body text, ensuring readability and clean design. Note: currently only Google Fonts are supported.
- Use subtle mystical symbols (sun/astros) as logo and minor accents.
- Implement a responsive layout with a max-width container (1200px) and fluid paddings.
