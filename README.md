# Arcana Smokes

E-commerce desenvolvido com Next.js para apresentação e navegação de produtos, com foco em uma experiência visual moderna, responsiva e organizada.

## Sobre o projeto

O **Arcana Smokes** é uma aplicação web de catálogo e compra de produtos, com funcionalidades como:

- navegação por categorias;
- barra de pesquisa;
- carrossel promocional na página inicial;
- página de detalhes do produto;
- carrinho de compras;
- fluxo de checkout.

O projeto foi estruturado para oferecer uma interface responsiva, com visual elegante e elementos visuais que reforçam a identidade da loja.

## Tecnologias utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Firebase**
- **Genkit**
- **Radix UI**
- **Lucide React**

## Funcionalidades

- Listagem de produtos por categoria
- Busca de produtos
- Destaque de promoções
- Visualização detalhada de produtos
- Adição e remoção de itens do carrinho
- Estrutura pronta para checkout
- Layout responsivo para desktop e mobile
